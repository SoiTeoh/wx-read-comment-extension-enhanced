# 微信读书评论增强版 v1.4.0-beta.1 · M4 兼容性

完成 M4：映射前检测 Reader 方法、正文画布和捕获能力；不兼容时显示失败原因与「重试定位」，保留已加载的公开评论与搜索。布局恢复复用评论，临时捕获精确恢复原生方法，Reader 发现不依赖固定 webpack 模块编号。

补充公共书籍／章节身份桥接，减少页面移除初始脚本导致的身份解析错误。

验证：30 项离线测试、7 项 headed Chromium 隔离故障检查、TypeScript 检查和生产构建通过。真实登录态上下滚动 Reader 验证了 483 条公开评论、40 个成功 range、字号／窗口变化、稳定滚动、切章及 popup 键盘操作。

仍为 Beta，M5–M6 待完成。正文定位支持上下滚动模式；横向模式仅验证降级提示及原生翻页，完整评论浏览未通过验收。详细结果见 `docs/m4-compatibility-acceptance.md`。

解压版本 ZIP 后，在浏览器扩展页开启开发者模式，选择「加载已解压的扩展程序」。升级后刷新微信读书页面。
