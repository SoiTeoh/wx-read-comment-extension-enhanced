## 1.5.0-beta.1 - 2026-10-11

本版汇总 M5 自动化验收与 I0–I4 互动扩展，让上下滚动页面在原有 UI 风格中使用原文操作和想法互动。左右双栏保持官方界面，不叠加插件增强。

### 新功能

- 评论 popup 新增复制、划线、写想法和 AI 问书操作栏；侧栏关闭时独立可用，支持日夜主题及窄窗口。
- 操作绑定核实的原文。划线打开官方工具，写想法进入原生编辑器，AI 问书预填原文；由用户选择样式、提交或发送。
- 想法卡片支持点赞／取消点赞和官方评论详情入口；按目标想法同步本人点赞状态与数量，未知数量不显示为零。
- 侧栏和 popup 共享互动状态，关闭原生详情后返回原卡片焦点；保留搜索、排序、密度与完整评论正文。

### 修复与性能

- 仅在上下滚动模式启动增强。退出该模式时清理插件 UI、章节会话和原文上下文，返回纵向正常恢复。
- 防止切章后继续旧章分页；过期详情或互动结果不重建旧界面，不更新新章卡片。
- 防止重复互动和覆盖未提交回复草稿。失败或结果不明确时提示手动刷新，不自动重试写入。
- 登录或原生能力恢复后可手动只读刷新状态；单条互动仅通知目标想法的侧栏和 popup，稳定滚动不新增映射或详情读取。

### 验证与使用范围

- 66 项离线测试、56 项 Chromium 受控场景、TypeScript 与生产构建通过。
- Windows 桌面 Playwright Chromium 的真实纵向入口、焦点恢复、日夜主题与窄窗口验收通过；用户确认点赞可用、回复能打开官方评论页面。
- 仍为 Beta：回复最终提交、真实回复分页与完整点赞／取消点赞服务端往返未由代理验收；原生回复与发布由用户显式提交。内部 Reader 更新可能导致部分入口降级。
- 扩展权限保持 `webRequest`、`storage`，站点范围仅 `https://weread.qq.com/*`；安装包不含测试浏览器、登录凭据或源码调试文件。

### 安装

下载 `wx-read-comment-extension-enhanced-v1.5.0-beta.1.zip`，解压到固定文件夹。在 Chrome 打开 `chrome://extensions`，开启“开发者模式”，点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的解压目录。更新后刷新微信读书页面，并切换到上下滚动阅读模式。
