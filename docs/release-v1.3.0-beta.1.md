本版完成开发计划 M0–M3，汇总自 v1.2.0-beta.1 发布后的阅读界面、popup／badge 和评论浏览改进。

### 新增与改进

- 搜索评论正文、引用或作者，并按可定位状态筛选。筛选只影响侧栏，清除后恢复完整评论；切章自动清空筛选。
- 舒适／紧凑两种密度，刷新后保留；长评论保持全文。
- Material You 风格侧栏与评论控件，适配日间／夜间主题。
- 改进 popup 键盘焦点、Escape 关闭、边缘定位和密集 badge 布局。

### 修复

- 侧栏固定在视口，正文滚动时仍可独立浏览评论。
- 评论点击让出微信读书原生选择工具栏、菜单和拖选操作。
- 修复划线 Enter 无法打开 popup、搜索输入框高度异常。

### 验收

14 项离线测试、TypeScript 检查及构建通过。桌面 Playwright Chromium 真实登录态测试覆盖两个章节的 237／483 条评论，以及筛选恢复、密度持久化、排序、切章、日夜主题和 popup。稳定布局下筛选及正文滚动不新增评论请求或 range 映射。

### 安装与更新

1. 下载附件 `wx-read-comment-extension-enhanced-v1.3.0-beta.1.zip` 并解压到固定目录。
2. 在 Chrome 打开 `chrome://extensions`，开启开发者模式。
3. 首次安装选择「加载未打包的扩展程序」，选中解压后包含 `manifest.json` 的目录。
4. 已安装用户可将新文件覆盖到原扩展目录，再点击扩展的「重新加载」并刷新微信读书页面。
5. 在微信读书 Reader 使用上下滚动阅读模式。

### 已知限制

仅展示接口返回的公开评论／想法，不提供点赞、回复或发布。部分历史 range 暂无法定位，仍可在侧栏阅读。动态「当前视口评论」过滤尚未启用。

仍为 Beta；开发计划 M4–M6 将继续推进。创建 GitHub Release 时选择标签 `v1.3.0-beta.1`，并勾选 **Set as a pre-release**。
